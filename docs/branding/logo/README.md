# Assets de logo oficiales

Extraídos **vectorialmente** del manual de identidad (`../IPTel-Manual de identidad.pdf`,
hojas 06 y 06b) con `pdftocairo`. Colores normalizados a los hex oficiales de la hoja 07:
violeta `#4f008c` (Pantone Medium Purple C) y naranja `#ff671b` (Pantone 165C).

| Archivo | Qué es |
|---------|--------|
| `iptel-logotipo.svg` | Logotipo violeta, vectorial. **Fuente de verdad.** |
| `iptel-logotipo-blanco.svg` | Variante blanca con punto naranja (para fondo violeta/oscuro). |
| `iptel-logotipo-master-4456px.png` | Raster maestro a 600 dpi, fondo transparente. |
| `iptel-isotipo-circulo-master-1681px.png` | Isotipo circular (hoja 06b), usado para el favicon. |

Derivados en uso dentro de este proyecto:
`client/src/assets/logo-iptel.svg`, `client/src/assets/logo-iptel-blanco.svg`,
`client/public/favicon.png` (copiado de iptel-web, generado del isotipo circular).

**No redibujar ni recolorear estos archivos.** Ver la regla "Logo e identidad" en `CLAUDE.md`.
